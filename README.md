- **Source code:** https://github.com/avinashq2/youtube-clone

A responsive recreation of the YouTube home page layout. It is UI only: all videos are demo cards with generated thumbnails (no real YouTube content or API).

## Features
- Fixed top navbar with menu button, logo, search bar, and icon buttons
- Collapsible sidebar (mini mode on desktop, slide-in drawer on mobile) with subscriptions list
- Scrollable category chips that filter the videos
- Responsive video grid with duration badges, hover zoom effect and loading skeletons
- Live search by title or channel, with an empty state
- Click a video to open a watch view with a play/pause demo, subscribe and like toggles
- Light and dark theme (saved with localStorage)

## Tech Stack
HTML5, CSS3 (Flexbox, Grid, CSS variables, media queries), JavaScript ES6 (DOM manipulation)

## Structure
`index.html` (layout), `style.css` (styling and responsive rules), `script.js` (data, rendering and interactions), `README.md`
